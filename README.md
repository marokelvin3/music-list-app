# 🎵 Music List App

A lightweight, responsive music tracking web application built with pure HTML, CSS, and Vanilla JavaScript. All data persists directly in your browser using `localStorage`.

## ✨ Features

- **Add Tracks**: Save music items with Title, Author / Artist, and Play status (Play or Not Play).
- **Edit Music**: Easily update the details of any track in your library.
- **Delete with Confirmation**: Prevents accidental deletions with a verification prompt.
- **Live Search**: Instant real-time search filtering across titles and artists.
- **Live Counter**: Displays total count of tracks at the top of the collection.
- **Persistent Storage**: All entries persist across refreshes via `localStorage` (no server, database, or login required).
- **Mobile Friendly**: Clean, modern responsive interface designed for both mobile and desktop screens.
- **Empty States**: Helpful messages when your collection is empty or when search queries yield no results.

## 🚀 Getting Started

No installation or build step is required:
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.

## 🛠️ Built With

- **HTML5**: Semantic document structure
- **CSS3**: Responsive flexbox/grid layout and modern styling
- **JavaScript (ES6+)**: DOM manipulation and `localStorage` API
